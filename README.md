# Buying the opening favourite

[View the slides (PDF)](us-election-opening-favorite.pdf) · [Download the editable PowerPoint](us-election-opening-favorite.pptx)

The presentation explains buying the market-favoured YES or NO side, building positions in orders of up to 10 shares, and holding until settlement. It includes yearly results, a sample holdings timeline, an order-fill example, and appendix comparisons.

This repository contains only the presentation and its PDF. Results are historical paper simulations.
